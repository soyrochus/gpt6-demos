# Temblor

Temblor is a Rust-based engine for Quake III Arena maps. Its browser demo runs the OpenArena map *Trial by Error*.

## Platform

Desktop web with keyboard, mouse, pointer lock, Web Audio and WebGPU.

## Stack

Single-threaded Rust/Wasm simulation and renderer with a static browser host.

## Player

A player opens the page, enters an independently authored arena and fights a local opponent to five frags. The bundled map works immediately. Owners can select local Quake III Arena archives. The arena and both scores must remain legible during movement.
